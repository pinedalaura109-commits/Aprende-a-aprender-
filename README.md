# 🧠 Aprende a Aprender

Plataforma web y móvil desarrollada como parte del proceso de formación en Análisis y Desarrollo de Software (SENA), orientada a evaluar, analizar y potenciar los estilos de aprendizaje de los estudiantes mediante diagnósticos personalizados y rutinas de estudio interactivas.

## 👥 Autora
* **Laura Ximena Pineda Castillo** (Ficha: 3186621)

## ✨ Características Principales
* **Test de Estilos de Aprendizaje:** Diagnóstico dinámico con cálculo de porcentajes mixtos.
* **Checklist Progresiva:** Pasos de estudio adaptados al perfil del usuario que se desbloquean progresivamente.
* **Temporizador de Estudio (Pomodoro):** Control de ciclos de enfoque y descansos con registro de rachas y progreso diario.
* **Sistema de Comentarios:** Código documentado y comentado para facilitar la lectura y el mantenimiento.

## 🛠️ Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla).
* **Backend / Base de datos:** Node.js, MySQL (MySQL Workbench).
* **Herramientas de Diseño y Prototipado:** Figma, Balsamiq, Draw.io.
* **Control de versiones:** Git / GitHub.

## 🌐 Servicios Web (API REST)
Para la gestión de usuarios, se han implementado los siguientes servicios:

### 1. Registro de Usuario
* **Ruta:** `/api/registro`
* **Método:** `POST`
* **Descripción:** Permite el registro de nuevos usuarios en la base de datos MySQL.

### 2. Autenticación de Usuario (Login)
* **Ruta:** `/api/login`
* **Método:** `POST`
* **Descripción:** Valida las credenciales del usuario (email/password) contra la base de datos para iniciar sesión.
